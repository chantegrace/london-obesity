# Health Inequalities Across London
## Project Overview

This project investigates the relationship between the health deprivation an childhood obesity across London boroughs.
The project demonstrates an end-to-end analytic workflow using Excelm SQL (SQLite) and Google Looker Studio.

## Objectives
- Clean and prepare public health datasets.
- Aggregrate LSOA-level deprivation data to borough level.
- Combine datasets using Excel.
- Validate and explore the data using SQL.
- Build an interactive dashboard.
- Identify patterns between deprivation and childhood obesity

## Tools used 
### Tool: Purpose
- Excel: Cleaning, PivotTables, XLOOKUP.
- SQLite: Data validation and SQL analysis.
- Looker Studio: Dashboard and visualisation.

## Dataset
### Trust for London 
Health Deprivation and Disability Rank (LSOA)
### National Child Measurement Program
Childhood obesity prevalence (2014 & 2024)

## Workflow
Public Data -> Excel Cleaning -> Pivot Tables -> XLOOKUP Merge -> SQLite -> Looker Studio Dashboard

## Key Findings
- Childhood obesity averaged 28.3% across the 32 London boroughs analysed.
- A negative relationship was observed between deprivation rank and childhood obesity.
- Several boroughs deviated from the overall trend, suggesting additional factors may influence childhood obesity.
